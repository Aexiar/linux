# 第一章：环境准备

## 1.1 概述

* `VMware Workstation` 是由全球知名虚拟化软件公司 VMware 开发的一款 `桌面端虚拟机软件`。

> [!NOTE]
>
> * ① 简单来说，它就像是一个 “系统多开器”，允许在现有的操作系统（Windows 或 Linux）中，像运行普通软件一样，同时安装和运行多个独立的其他操作系统（如多个版本的 Windows、Linux、MacOS 等）。
> * ② 这些在软件内运行的系统被称为 “虚拟机（Virtual Machine, VM）”，而原本的电脑系统被称为 “宿主机（Host）”。

* VMware Workstation 在软件开发、系统测试、网络工程等领域被广泛使用，如下所示：

| 作用                     | 描述                                                         |
| ------------------------ | ------------------------------------------------------------ |
| ① 多系统并行运行         | 无需重新启动电脑，就可以在 Windows 10/11 上同时运行 Ubuntu、CentOS、Windows 7 等多个系统，方便进行跨平台操作。 |
| ② 安全隔离与软件测试     | 虚拟机与宿主机之间是隔离的。可以在虚拟机里测试未知软件、打开可疑链接或运行病毒样本，即使虚拟机彻底崩溃或中毒，也不会对你的真实电脑造成任何影响。 |
| ③ 快照（Snapshot）与克隆 | 这是最强大的功能之一。可以为虚拟机的某个状态创建“快照”（类似游戏存档）。如果后续操作失误导致系统搞砸了，只需一键就能“读档”恢复到快照时的完好状态。 |
| ④ 模拟复杂的网络环境     | 它可以虚拟出多块网卡、交换机、路由器，让多台虚拟机组成一个复杂的局域网，非常适合网络工程师用来测试网络拓扑、服务器集群或进行渗透测试。 |
| ⑤ 开发与搭建开发环境     | 开发者可以在虚拟机中配置干净的开发环境（Docker、Kubernetes、各种数据库），避免污染宿主机，且方便打包分发给团队其他成员。 |

>
> * ① **硬件资源层（Hardware）：** 真实电脑硬件（CPU、内存、硬盘、显卡）。
> * ② **宿主操作系统层（Host OS）：** 平时用的 Windows 或 Linux 系统。
> * ③ **VMware 软件层（Hypervisor）：** 运行在宿主系统之上的软件。它扮演着 `“中间协调官”` 和  `“魔术师”` 的角色：
>   * **硬件抽象与拦截：** 它把宿主机的物理硬件资源（16核 CPU、32G 内存）切分成很多虚拟的碎片。当虚拟机里的系统（Guest OS）发出读取硬盘或计算指令时，VMware 会拦截这些指令，并将其翻译成宿主机能理解的普通软件请求，再提交给宿主机处理。
>   * **VMM（虚拟机监视器）：** 为每个虚拟机创造一个全虚拟的硬件环境（虚拟 CPU、虚拟内存、虚拟网卡等）。虚拟机里的系统根本不知道自己运行在软件里，它以为自己独占了一台真实的电脑。
> * ④ **客户操作系统层（Guest OS）：** 运行在虚拟机内部的系统。它们相互隔离，互不干扰，通过 VMware 软件安全地共享宿主机的物理资源。
>
