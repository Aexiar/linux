# 第一章：计算机系统

## 1.1 概述

* `计算机`（Computer）：俗称 `“电脑”` ，是一种能接收和存储信息，并按照存储在其内部的程序对海量数据进行自动、高速的处理，然后将处理结果输出的现代化智能电子设备。

> [!NOTE]
>
> 如果脱离冷冰冰的定义，在现代社会中，计算机本质上是一个“极其听话的 “数字纺织机” —— 我们给它编织图纸（程序/代码），它就把 0 和 1 的数据流编织成网页、游戏、AI 聊天界面或者火箭发射的轨道数据。

* `计算机` 有很多形式，如：生活中常见的 `家用电脑`（台式机、笔记本、智能手机、平板等）以及生产环境中提供重要业务支撑的各种 `服务器`（阿里云服务器、腾讯云服务器、戴尔服务器等），如下所示：

## 1.2 计算机的核心本质

* `计算机` 的 `核心本质` 是：`输入 → 处理 → 输出` ，如下所示：

> [!NOTE]
>
> ::: details 点我查看 计算机的核心本质
>
> 不管是一台超级计算机、智能手机，还是电饭煲里的微型芯片，它们的工作模式都逃不出这个经典的模型：
>
> * `输入（Input）`： 接收外界的信息，如：敲击键盘、滑动手机屏幕、麦克风录入声音。
> * `处理（Process）`： 计算机最核心的功能，如：将输入的信息转化成二进制数据（0 和 1），并进行算术运算或逻辑判断。
> * `存储（Storage）`： 把暂时用不到或需要长期保存的数据存起来。
> * `输出（Output）`： 将处理完的数字结果，转换成人类能看懂的形式，如：屏幕上的画面、喇叭里的声音、打印机出来的纸张。

## 1.3 计算机系统的组成

* 一个完整的 `计算机系统` 由 `硬件系统` 和 `软件系统` 两大部分组成，如下所示：

> [!NOTE]
>
> 为了让概念更形象，我们可以把 **`计算机系统`** 理解为一辆汽车，如下所示：
>
> * **`硬件系统`** 就像是汽车的车架、发动机和车轮（看得见、摸得着的实体）。
> * **`软件系统`** 则是驾驶员的操控指令、导航系统和车载电脑的算法（看不见，但决定了汽车如何运行）。

> [!NOTE]
>
> ::: details 点我查看 硬件系统和软件系统
>
> * `硬件系统`（Hardware）是 `计算机系统` 的 `物理基础`，通常由经典的 `冯·诺依曼架构` 衍生而来，如下所示：
>
>   * ① `中央处理器`（CPU）：系统的 `“大脑”` ，包含 `运算器`（负责数学和逻辑运算）和 `控制器`（负责指挥全身）。
>
>   * ② `存储器`：存放程序和数据，分为 `内存` 和 `外存` 。
>     * `内存（主存）`：速度快，但断电后数据会丢失，CPU 直接与之交换数据，如：内存条。
>     * `外存（辅存）`：容量大、断电后数据不丢失，如：固态硬盘 SSD、机械硬盘 HDD。
>
>   * ③ `输入设备`：向计算机传送数据的设备，如：键盘、鼠标、麦克风。
>
>   * ④ `输出设备`：将计算机处理结果展示给用户的设备，如：显示器、音响、打印机。
>
>
> * `软件系统`（Software）是 `计算机系统` 的 `灵魂` ，没有软件的硬件被称为“裸机”，它通常分为两大类：
>
>   * ① `系统软件`：负责管理、监控和维护计算机资源，给应用软件提供支持的基础平台，如：操作系统（Linux、Windows、macOS）、编译器/解释器、数据库管理系统、驱动程序。
>
>   * ② `应用软件`：为了解决各类用户特定需求而开发的专用程序，如：办公软件（Office）、浏览器（Chrome）、音视频播放器（PotPlayer）等。
>

## 1.4 计算机是如何工作的（从 0 和 1 到万物）

* 计算机能够运行复杂的 3D 游戏、进行 AI 绘画、或者支撑起整个互联网，其底层逻辑只是无数个 `0 和 1` 的快速组合，如下所示：

> [!NOTE]
>
> ::: details 点我查看 计算机的进化
>
> 从 `最物理的“电信号”` 到 `千变万化的“万物”` ，`计算机的进化` 可以分为 `6 个关键层级` ：
>
> * ① `物理层`：开关与电信号（0 与 1 的诞生），即：在最底层，计算机没有思想，只有**电路**。
>   * **电压的高低**：电路里只有两种状态——高电压和低电压。
>   * **代言人 0 和 1**：为了方便计算，科学家把“低电压”定义为 **0**，“高电压”定义为 **1** 。
>   * **晶体管**：这是计算机的细胞。它本质上就是一个 **电控开关** 。如果给它通电，它就允许电流通过（1），断电就不通过（0）。现代 CPU 里集成了几十亿甚至上百亿个这样的微型开关。
> * ② `逻辑门层`：用开关做 “逻辑判断” ，即：光有 0 和 1 还不够，必须让它们碰撞出火花。通过将几个晶体管巧妙地组合在一起，就形成了 **逻辑门** ，这些逻辑门是计算机具备“思考”能力的起点，通过这些简单的逻辑，计算机开始能够做对错判断。
>   * **与门（AND）**：必须两个输入都是 1 ，输出才是 1 。
>   * **或门（OR）**：只要有一个输入是 1 ，输出就是 1 。
>   * **非门（NOT）**：输入是 0 ，输出就是 1 ；输入是 1 ，输出就是 0 。
> * ③ `硬件电路层`：从逻辑到算术（CPU 的诞生），即：把成千上万个逻辑门拼装在一起，奇迹发生了：**计算机可以做数学题了** 。
>   * **加法器（Adder）**：用逻辑门组合出来的电路，可以实现二进制的 $0+0=0$，$0+1=1$，$1+1=10$（逢二进一）。
>   * **CPU 的核心（ALU）**：算术逻辑单元（ALU）就是由无数加法器和逻辑门构成的，它负责所有的数学运算。
>   * **时钟信号**：CPU 内部有一个“脉搏”（晶振），它一秒钟跳动几十亿次，如：3.0 GHz 就是每秒跳动 30 亿次。脉搏每跳一下，晶体管就集体切换一次开关状态，数据就向前流动一步。
> * ④ `指令集与机器语言层`：给硬件下命令，即：电路做好了，怎么控制它？答案是 **指令**
>   * 硬件工程师规定：当 CPU 接收到一串特定的 0 和 1（比如 `10110000`）时，就代表“把数据复制到寄存器”；收到 `00000001` 时，代表“做加法”。
>   * 这就叫 **机器语言**（也就是指令集，如 x86 或 ARM），这是硬件唯一能直接听懂的语言。
> * ⑤ `软件与操作系统层`：从枯燥代码到精美界面，即：天天写 0 和 1 会让程序员疯掉，于是人类开始一层层地“套娃”
>   * **汇编语言**：用人类能看懂的单词代替 0 和 1，如：用 `ADD` 代替 `00000001` 。
>   * **高级语言（C/C++/Java/Python）**：更接近人类语言。程序员写下 `if (x > 0)`，然后通过**编译器**，自动把这句话翻译成成千上万行的 0 和 1 。
>   * **操作系统（OS）**：像 Windows、macOS 或 Linux，它们是一个超级管家。它把底层的硬件细节（读写硬盘、分配内存）全部封装起来，只给用户和软件留下好用的图形界面和接口（API）。
> * ⑥ `应用层`：0 和 1 变化出的万物，即：当软件和屏幕结合，0 和 1 终于变成了我们眼中的数字世界
>   * **文字**：屏幕上的每一个字，对应着一组固定的数字，如：通过 UTF-8 编码，“中” 字在计算机眼里就是一串二进制数。
>   * **颜色与图像**：屏幕上的每个像素点由红（R）、绿（G）、蓝（B）三原色组成。用 8 位二进制（0-255）来表示每种颜色的亮度，如：`(255, 0, 0)` 就是纯红色。我们看到的一张照片，在计算机里就是一张巨大的 “数字矩阵”。
>   * **声音**：麦克风把声波振动转化为不同大小的电压（模拟信号），计算机再把这些电压高低量化为一串串 0 和 1 存下来。播放时，再反向把 0 和 1 变成电流去震动喇叭。
>   * **网络**：当你刷视频时，网线或 Wi-Fi 信号其实是以“有电/没电”或“有波形/没波形”的高频闪烁，把数以亿计的 0 和 1 从服务器传送到你的手机上。
>
