#### 1.2.1.3 安装和配置 SSH 

* 安装 OpenSSH 服务端：

::: code-group

```bash
# 刷新软件列表
sudo apt update -y
# 默认情况下，RockyLinux 安装了 OpenSSH 客户端和服务端
# 默认情况下，Ubuntu 只安装了 OpenSSH 客户端
sudo apt install openssh-server -y
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-30/2026-07-30-13-12-33.gif)
```

:::

* 设置 root 密码：

::: code-group

```bash
sudo passwd root
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-30/2026-07-30-13-17-51.gif)
```

:::

* 开启 root 远程 SSH 登录：

::: code-group

```bash
# 修改 SSH 的配置文件
sudo sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin yes/' /etc/ssh/sshd_config
# 重启 SSH 服务
sudo systemctl restart ssh
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-30/2026-07-30-13-22-18.gif)
```

:::

* 开启 root 用户的图形界面登录：

::: code-group

```bash
# 修改 GDM3 配置
sudo sed -i '/\[security\]/a AllowRoot=true' /etc/gdm3/custom.conf
# 查询是否修改成功
grep -n "AllowRoot" /etc/gdm3/custom.conf
# 修改 PAM 配置 (解除 root 登录限制)
sudo sed -i 's/^auth\s\+required\s\+pam_succeed_if.so.*user.*root.*/#&/' /etc/pam.d/gdm-password
sudo sed -i 's/^auth\s\+required\s\+pam_succeed_if.so.*user.*root.*/#&/' /etc/pam.d/gdm-autologin
# 查询是否修改成功
grep "pam_succeed_if.so" /etc/pam.d/gdm-password /etc/pam.d/gdm-autologin
# 重启系统
sudo reboot
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-30/2026-07-30-13-45-18.gif)
```

:::
