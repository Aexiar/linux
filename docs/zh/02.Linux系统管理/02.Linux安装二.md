## 1.2 安装 Ubuntu 服务器版

### 1.2.1 Ubuntu 24.04

#### 1.2.1.1 创建虚拟机

- ① 点击 `创建新的虚拟机`，如下所示：

> [!NOTE]
>
> 该步骤类似于购买一台 `没有安装操作系统` 的裸机！！！



* ② 选择 `自定义（高级）` ，点击 `下一步`，如下所示：



* ③ 点击 `下一步` ，如下所示：



* ④ 选择 `稍后安装操作系统` ，点击 `下一步`，如下所示：



- ⑤ 点击 `Linux` ，选择 `RockyLinux 64 位` ，点击 `下一步`，如下所示：



- ⑥ 创建虚拟机的安装位置，如下所示：

::: code-group

```powershell
mkdir -Force "D:\develop\vms\Rocky\Rocky10\10.0.0.21" 
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-29/2026-07-29-09-27-27.gif)
```

:::



- ⑦ 修改 `虚拟机名称` 以及 `位置` ，点击 `下一步`，如下所示：

> [!NOTE]
>
> * :one: 虚拟机名称：`10.0.0.21` 。
> * :two: 位置：`D:\develop\vms\Rocky\Rocky10\10.0.0.21` 。



* ⑧ 根据 `需求` 设置 `处理器` 的 `数量`，点击 `下一步`，如下所示：

> [!NOTE]
>
> `不要` 超过 `宿主机` 中 `处理器` 的 `数量`；否则，VMware 将会报错！！！



- ⑨ 根据 `需求` 设置 `内存` 的 `大小`，点击 `下一步`，如下所示：

> [!NOTE]
>
> `不要` 超过 `宿主机` 中 `内存` 的 `总大小`；否则，VMware 将会报错！！！



* ⑩ 选择 `网络类型` 为 `NAT` 模式，点击 `下一步`，如下所示：



* ⑪ 根据 `需求` 设置 `I/O 控制器` 的 `类型`，点击 `下一步`，如下所示：



- ⑫ 根据 `需求` 设置 `磁盘` 的 `类型`，点击 `下一步`，如下所示：

> [!NOTE]
>
> 尽量选择 `SCSI` 类型，原因是在添加磁盘的时候，可以不重启虚拟机的情况下，让其动态感知！！！



* ⑬ 根据 `需求` 选择`磁盘`，点击 `下一步`，如下所示：



* ⑭ 根据 `需求` 指定`磁盘`的 `容量`，点击 `下一步`，如下所示：



* ⑮ 点击 `完成`，如下所示：



* ⑯ 将配置好的 `虚拟机` 拖到 `指定的文件夹`，如下所示：



* ⑰ 将配置好的 `虚拟机` 关联 `对应的镜像文件`，如下所示：



#### 1.2.1.2 安装 Linux

* ① 点击 `开启此虚拟机` ，如下所示：



* ② 通过键盘的 `↑` 或 `↓` ，选择 `Install Rocky Linux 9.8` ，并点击 `Enter` 键，如下所示：



* ③ 选择 `安装语言` 为 `简体中文`，并点击 `继续` ，如下所示：



* ④ 配置 `安装目标位置` ，如下所示：



* ⑤ 配置 `软件选择` 为 `最小安装` ，如下所示：



* ⑥ 配置 `用户设置` ，如下所示：

> [!NOTE]
>
> * :one: 账户和密码：
>
> | 账户 | 密码   | 角色       |
> | ---- | ------ | ---------- |
> | root | 123456 | 系统管理员 |
> | x    | 123456 | 普通用户   |
>
> * :two: 在生产环境中，密码必须复杂且经常更新！！！



* ⑦ 配置 `网络和主机名` ，如下所示：

> [!NOTE]
>
> * :one: 主机名：`rockyLinux10` 。
> * :two: 网络配置：
>
> | IP        | 子网掩码      | 网关     | DNS      |
> | --------- | ------------- | -------- | -------- |
> | 10.0.0.21 | 255.255.255.0 | 10.0.0.2 | 10.0.0.2 |



* ⑧ 点击 `开始安装` ，如下所示：



* ⑨ 漫长的等待，如下所示：



* ⑩ 点击 `重启系统` ，如下所示：



* ⑪ 输入 `用户名` 和 `密码` 进行 `系统登录`，如下所示：



* ⑫ 查看分配的 IP 地址，如下所示：



* ⑬ 拍摄快照，如下所示：

* ② 配置 `SSH 远程连接` ，如下所示：



#### 1.2.1.4 设置语言环境

* ① 查看当前的语言环境：

::: code-group

```bash
localectl status
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-29/2026-07-29-10-05-29.gif)
```

:::

* ② 查看系统中已安装的语言包：

::: code-group

```bash
rpm -qa | grep glibc-langpack
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-29/2026-07-29-10-12-09.gif)
```

:::

* ③ 安装所需要的语言包：

::: code-group

```bash
# 安装中文语言包
sudo dnf install glibc-langpack-zh -y
# 安装英文语言包
sudo dnf install glibc-langpack-en -y
# 安装所有语言包（不建议做，因为通常中文+英文组合最好）
sudo dnf install glibc-langpack-* -y
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-29/2026-07-29-10-12-55.gif)
```

:::

* ④ 列出系统支持的可用语言环境：

::: code-group

```bash
localectl list-locales
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-29/2026-07-29-10-14-30.gif)
```

:::

* ⑤ 临时切换语言环境：

::: code-group

```bash
# 查看当前语言环境
echo $LANG 
# 临时切换语言环境，退出终端失效
LANG=en_US 
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-29/2026-07-29-10-19-47.gif)
```

:::

* ⑥ 永久切换语言环境：

::: code-group

```bash
# 切换中文语言环境
sudo localectl set-locale LANG=zh_CN.UTF-8
# 设置英文语言环境
sudo localectl set-locale LANG=en_US.UTF-8
# 重新加载环境变量，使得当前终端立即生效
source /etc/locale.conf
# 验证是否切换成功
localectl
```

```md:img [cmd 控制台]
![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-29/2026-07-29-10-22-37.gif)
```
