# 第一章：初识计算机语言

## 1.1 什么是计算机语言？

* 计算机本质上就是一台按照指令工作的电子设备，如：`我们对计算机说：“计算两个数的和”`，计算机其实并不能直接理解这句话。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-08-16/2026-08-16-08-00-47.gif)

* 计算机中的 CPU 最终能够执行的是 `机器指令` ，如：`10110000 01100001 ...` 。

> [!NOTE]
>
> 机器指令：由二进制编码表示的指令，即：机器语言。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-08-16/2026-08-16-08-01-05.gif)

* 如果所有的程序都需要人类直接编写二进制指令，程序开发将会变得非常困难；于是，人类设计出了各种更加容易表达算法和逻辑的语言，即：计算机语言。

> [!NOTE]
>
> `计算机语言` 是 `人与计算机` 之间进行 `信息表达` 和 `程序控制` 的一套 `形式化语言`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-08-16/2026-08-16-08-04-20.png)

* 对于我们学习编程而言，最重要的一类计算机语言就是编程语言，如：C、C++、Java 等。

> [!NOTE]
>
> 掌握编程语言就能使用计算机解决实际问题，即：编程语言 → 表达算法和逻辑 → 计算机理解并执行 → 解决实际问题。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-08-16/2026-08-16-08-16-25.png)

## 1.2 自然语言 VS 计算机语言

* 自然语言非常灵活，如：`帮我把这个文件打开`。即使表达得不完全准确，人通常也能理解。

> [!NOTE]
>
> * ① 自然语言：灵活、宽松，更接近人类思维。
> * ② 自然语言允许表达不完全正确，但人仍能理解并完成任务，这正体现了自然语言的灵活性和强大的人类理解能力。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-08-16/2026-08-16-08-35-56.png)

* 计算机语言要求更加严格，如：C 语言中的 `printf("Hello World\n");` 少一个 `;` 就会导致编译失败。

> [!NOTE]
>
> * ① 计算机语言：严格、精确，更接近机器思维。
> * ② 计算机只能严格按照规则理解和执行程序，任何细微的错误都可能导致编译失败或运行出错。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-08-16/2026-08-16-08-50-59.png)

* `自然语言` 和  `计算机语言` 的区别和联系，如下所示：

| 语言类别   | 特点                                                         |
| ---------- | ------------------------------------------------------------ |
| 自然语言   | 灵活多样，表达自由                                           |
| ^^         | 容错性高，不必完全正确                                       |
| ^^         | 依赖上下文、经验和常识理解                                   |
| ^^         | 面向人类交流                                                 |
| 计算机语言 | 规则严格，必须完全正确                                       |
| ^^         | 容错性低，任何错误都可能导致失败                             |
| ^^         | 依赖编译器或解释器的严格检查                                 |
| ^^         | 面向机器执行                                                 |
| 共同目标   | 用清晰的方法表达思想，让对方（人或计算机）准备理解并完成任务！ |

* 【问】现在的软件已经这么多了，为什么还需要学习编程语言？
* 【答】因为使用计算机和控制计算机，是两个不同的层次。

* ② 学习编程语言，就是学习如何把自己的想法转化为计算机能够执行的程序。

## 1.4 学习计算机语言到底在学习什么？

* :one: 从表面看，我们学习的是计算机语言的语法等，如：if、for、while、int、printf 等。



* :two: 其实，我们真正学习的是：问题 --> 分析 --> 抽象 --> 算法 --> 数据结构 --> 程序 --> 计算机执行。



* :three: 换言之，学习计算机语言不仅仅在学习语法等，更重要的是培养：逻辑思维，抽象能力、自动化能力。
