# 第一章：数据类型（🎯）

## 1.1 概述

### 1.1.1 数据类型是什么？

* `数据类型` 决定了 `数据的身份、大小、解释方式和可进行的操作`，如下所示：

> [!NOTE]
>
> * ① `数据类型` 用来告诉编译器：`一块数据是什么、占用多少内存、应该怎么解释以及允许对它进行什么操作` 。
> * ② 可以将 `数据类型` 理解为给内存中的二进制数据贴上 `说明书`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-09-08/2026-09-08-13-55-57.png)



* 示例：

```c
#include <stdio.h>

/*
 * 数据类型类似于给内存中的二进制贴上说明书
 */
int main(void) {

    // int 是数据类型，表示整数
    int a = 18; // [!code highlight]
    // double 是数据类型，表示浮点数
    double price = 19.22; // [!code highlight]
    // char 是数据类型，表示字符
    char grade = 'A'; // [!code highlight]

    return 0;
}
```

### 1.1.2 为什么需要数据类型？

* 计算机内存中本质只有二进制；那么，对于同一段二进制，不同的数据类型有不同的含义。

> [!NOTE]
>
> `二进制：0100 0001` 可以被解释为 `整数：65` ，也可以被解释为 `字符：'A'` 。



* 示例：

```c
#include <stdio.h>

/*
 * 同一段二进制，不同的数据类型可能有不同的含义。
 */
int main(void) {

    int c = 0b01000001; // [!code highlight]

    // 变量 c 在内存中数据是没有变化的，只是解释方式不同
    
    // A
    printf("%c\n", c);  // [!code highlight]
    // 65
    printf("%d\n", c);  // [!code highlight]

    return 0;
}
```

### 1.1.3 数据类型的本质

* 数据类型主要决定了四件事情，如下所示：

::: details 点我查看 具体细节

* ① 数据的含义：数据类型告诉编译器，这段二进制数据应该被当成整数、小数、字符等什么内容来解释。
* ② 占用的内存大小：数据类型决定一个变量通常需要占用多少字节的内存空间。
* ③ 能表示的数值范围：数据类型决定这个变量能够存储的最小值和最大值。
* ④ 可以进行哪些操作：数据类型决定这个数据可以参与哪些运算，如：加减乘除、取模、比较或位运算等。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-09-08/2026-09-08-14-21-18.png)



* 示例：

```c
#include <stdio.h>

int main(void) {
    int a = 10;
    int b = 20;

    /* 因为 a 和 b 都是整数，
     * 所以编译器知道 a + b 的值也是整数，
     * 所以 c 的类型也应该是整数
     */
    int c = a + b;
    printf("c = %d\n", c);

    return 0;
}
```
