# 第一章：数据类型（🎯）

## 1.1 概述

### 1.1.1 数据类型是什么？

* `数据类型` 决定了 `数据的身份、大小、解释方式和可进行的操作`，如下所示：

> [!NOTE]
>
> * ① `数据类型` 用来告诉编译器：`一块数据是什么、占用多少内存、应该怎么解释以及允许对它进行什么操作` 。
> * ② 可以将 `数据类型` 理解为给内存中的二进制数据贴上 `说明书`。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-09-08/2026-09-08-13-55-57.png)



* 示例：

```c
#include <stdio.h>

/*
 * 数据类型类似于给内存中的二进制贴上说明书
 */
int main(void) {

    // int 是数据类型，表示整数
    int a = 18; // [!code highlight]
    // double 是数据类型，表示浮点数
    double price = 19.22; // [!code highlight]
    // char 是数据类型，表示字符
    char grade = 'A'; // [!code highlight]

    return 0;
}
```

### 1.1.2 为什么需要数据类型？

* 计算机内存中本质只有二进制；那么，对于同一段二进制，不同的数据类型有不同的含义。

> [!NOTE]
>
> `二进制：0100 0001` 可以被解释为 `整数：65` ，也可以被解释为 `字符：'A'` 。



* 示例：

```c
#include <stdio.h>

/*
 * 同一段二进制，不同的数据类型可能有不同的含义。
 */
int main(void) {

    int c = 0b01000001; // [!code highlight]

    // 变量 c 在内存中数据是没有变化的，只是解释方式不同
    
    // A
    printf("%c\n", c);  // [!code highlight]
    // 65
    printf("%d\n", c);  // [!code highlight]

    return 0;
}
```

### 1.1.3 数据类型的本质

* 数据类型主要决定了四件事情，如下所示：

::: details 点我查看 具体细节

* ① 数据的含义：数据类型告诉编译器，这段二进制数据应该被当成整数、小数、字符等什么内容来解释。
* ② 占用的内存大小：数据类型决定一个变量通常需要占用多少字节的内存空间。
* ③ 能表示的数值范围：数据类型决定这个变量能够存储的最小值和最大值。
* ④ 可以进行哪些操作：数据类型决定这个数据可以参与哪些运算，如：加减乘除、取模、比较或位运算等。

:::

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-09-08/2026-09-08-14-21-18.png)



* 示例：

```c
#include <stdio.h>

int main(void) {
    int a = 10;
    int b = 20;

    /* 因为 a 和 b 都是整数，
     * 所以编译器知道 a + b 的值也是整数，
     * 所以 c 的类型也应该是整数
     */
    int c = a + b; // [!code highlight]
    printf("c = %d\n", c);

    return 0;
}
```

### 1.2.6 数据类型的长度

#### 1.2.6.1 概述

* 每种数据类型都有自己的长度，使用不同的数据类型创建的变量，其长度也会有所差异。

#### 1.2.6.2 sizeof 操作符

* 格式：

```c
sizeof(类型)

sizeof 表达式    
```

> [!NOTE]
>
> * ① sizeof 是一个关键字，也是操作符，专门是用来计算 sizeof 的操作数的类型长度的，单位是字节。
> * ② sizeof 操作符的操作数可以是类型，也可是变量或者表达式。
> * ③ sizeof 的操作数如果不是类型，是表达式的时候，可以省略掉后边的括号的。
> * ④ sizeof 后边的表达式是不真实参与运算的，根据表达式的类型来得出大小。
> * ⑤ sizeof 的计算结果是 `size_t`  类型的，如果要打印在屏幕上，可以使用  `%zu` 的占位符。
> * ⑥ 数据类型长度和取值范围的 [官方文档](https://zh.cppreference.com/c/language/arithmetic_types) 地址。



* 示例：

::: code-group

```c [main.c]
#include <stdio.h>

int main(void) {
    
    int a = 10;
    printf("%zu\n", sizeof(a)); // 4
    // sizeof 的操作数如果不是类型，是表达式的时候，可以省略掉后边的括号的。
    printf("%zu\n", sizeof a);        // 4
    printf("%zu\n", sizeof(int));     // 4
    printf("%zu\v", sizeof(3 + 3.5)); // 8

    return 0;
}
```

```c [main.c]
     * sizeof 中表达式不计算
     *
     * sizeof 在代码进行编译的时候，就根据表达式的结果的类型，推到并确定了类型的长度，
```

## 1.3 signed 和 unsigned

### 1.3.1 概述

* C 语言中使用 `signed`  或 `unsigned` 关键字修饰 `整型家族`（`字符型` 和 `整型`）。

> [!NOTE]
>
> * ① signed（有符号）是关键字，如果修饰一个整型家族的类型，则表示该类型修饰的变量可以是：正数、负数和 0。
> * ② unsigned（无符号）是关键字，如果修饰一个整型家族的类型，则表示该类型修饰的变量只能是：正数和 0（自然数） 。

### 1.3.2 整数类型

* 对于 int 类型而言，默认是 signed 修饰的；换言之，int 等同于 signed int。

```c
signed int a ; // 等同于 int a ;
```

* 对于 int 类型而言，也可以不带正负号，只表示非负整数，则必须使用关键字 unsigned 来修饰。

```c
unsigned int a ;
```

> [!NOTE]
>
> 整数变量声明为 unsigned 的好处是，同样长度的内存能够表示的最大整数值，增大了一倍。

* 整型的取值范围可以在 `limits.h` 中进行查看。



* 示例：

::: code-group

```c [main.c]
#include <stdio.h>
#include <limits.h>

int main(void) {

    /*
     * 输出各种整数类型的取值范围
     */
    printf("signed short 的取值范围：%d 到 %d\n", SHRT_MIN, SHRT_MAX);
    printf("unsigned short 的取值范围：0 到 %u\n", USHRT_MAX);

    printf("signed int 的取值范围：%d 到 %d\n", INT_MIN, INT_MAX);
    printf("unsigned int 的取值范围：0 到 %u\n", UINT_MAX);

    printf("signed long 的取值范围：%ld 到 %ld\n", LONG_MIN, LONG_MAX);
    printf("unsigned long 的取值范围：0 到 %lu\n", ULONG_MAX);

    printf("signed long long 的取值范围：%lld 到 %lld\n", LLONG_MIN, LLONG_MAX);
    printf("unsigned long long 的取值范围：0 到 %llu\n", ULLONG_MAX);

    return 0;
}
```

## 1.5 数据类型转换

### 1.5.1 概述

* `数据类型转换` 就是把一种数据类型的值，转换成另一种数据类型。

> [!NOTE]
>
> 类型转换改变的是“如何解释和表示这个值”，有时会导致精度丢失、溢出或数据含义发生变化。

* C 语言中的数据类型转换分为两类，如下所示：

```markmap
# 数据类型转换
## 隐式类型转换（自动类型转换，编译器自动完成）
### 赋值
### 算术运算
### 函数参数
### 函数返回值
### 比较运算
## 显示类型转换（强制类型转换，程序员主动完成）
### (type)value
```

> [!NOTE]
>
> * ① 不同类型参与运算时，C 经常会先自动转换成共同类型。
>
> * ② `char`、`short` 参与很多运算时会先提升为 `int`。
>
> * ③ 大范围转小范围、浮点转整数，可能丢失数据。
>
> * ④ `signed` 和 `unsigned` 混合运算，是最需要警惕的类型转换之一。

### 1.5.2 隐式类型转换（自动类型转换）

* 所谓的隐式类型转换是编译器自动帮我们完成的。

> [!NOTE]
>
> * ① 从小范围类型转换为大范围类型，通常比较安全，不会丢失精度。
> * ② 从大范围类型转换为小范围类型，本质上是向 0 截取，会丢失精度，不是很安全（慎用）。
> * ③ 对于从大范围类型转换为小范围类型，在 Java 中的编译器会直接报错（除非程序员主动强制转换）；而 C 语言不会，这也是许多人为什么吐槽 C 语言不安全的原因之一（也可以让 CLANG 开启告警，使其编译不通过）。
> * ④ 在发生算术运算之前，会进行整型提升，如：char --> int 以及 short --> int。



* 示例：小范围 --> 大范围

::: code-group

```c [main.c]
#include <stdio.h>

int main(void) {
    /*
     * 小范围 --> 大范围
     */
    
    int a = 10;
    double d = a; // [!code highlight]

    printf("a = %d\n", a);
```

### 1.5.3 显示类型转换（强制类型转换）

* 格式：

```c
目标数据类型 变量 = (目标数据类型)表达式;
```

> [!NOTE]
>
> * ① 显式类型转换 = 强制类型转换。
> * ② 当两个不同类型的数据进行运算时，C 通常会先把它们转换成某个共同类型。
> * ⑤ 整数 --> 浮点数，通常比较安全；浮点数 --> 整数，会丢失精度。
> * ⑥ 大整数 --> 小整数，可能造成数据丢失。
> * ⑦ `signed` 和 `unsigned` 转换最容易出问题，不要随意混用有符号整数和无符号整数。



* 示例：大范围 --> 小范围（可能损失精度）

::: code-group

```c [main.c]
#include <stdio.h>

int main(void) {
    /*
     * 大范围 --> 小范围
     */

    double d = 3.14;
    // 强制类型转换
    int a = (int)d; // [!code highlight]

    printf("d = %f\n", d);
    printf("a = %d\n", a);

    return 0;
}
```

### 1.5.4 指针的类型转换

* 对于 `普通对象指针` 是可以隐式转换为 `void *` 类型的，如下所示：

```c
int num = 10;
int *p = &num;

void* ptr = p ;
```

* 对于 `void *`  指针类型也可以自动转换为 `普通对象指针`（不推荐），如下所示：

```c
int *p = malloc(sizeof(int)); // 合法，但不推荐
```

```c
int *p = (int*)malloc(sizeof(int)); // 推荐
```



* 示例：

::: code-group

```c [main.c]
#include <stdio.h>
#include <string.h>

/**
 * 核心：万能交换函数。不管传入的是 int、float 还是指针，只要告诉它大小就能交换。
 * @param a 指针地址
 * @param b 指针地址
 * @param size
 */
static void swap(void *a, void *b, const size_t size) {
    char temp[size];           // 开辟一块临时内存
    memcpy(temp, a, size);     // 把 a 的内存拷贝到 temp
    memcpy(a, b, size);        // 把 b 的内存拷贝到 a
    memcpy(b, temp, size);     // 把 temp 的内存拷贝到 b
}

int main() {
    // 1. 交换整数
    int x = 10, y = 20;
    // 类似于 void* ptr = &x
    // 类似于 void* ptr = &y
    swap(&x, &y, sizeof(int)); // [!code highlight]
    printf("整数交换: x=%d, y=%d\n", x, y);

    // 2. 交换浮点数
    float f1 = 3.14f, f2 = 2.71f;
    swap(&f1, &f2, sizeof(float));
    printf("浮点交换: f1=%.2f, f2=%.2f\n", f1, f2);

    // 3. 交换字符串指针
    char *s1 = "Hello", *s2 = "World";
    swap(&s1, &s2, sizeof(char*));
    printf("指针交换: s1=%s, s2=%s\n", s1, s2);

    return 0;
}
```
