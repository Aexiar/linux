# 第一章：关键字和标识符（🔥）

## 1.1 关键字

### 1.1.1 概述

* 在 C 语言中，`关键字` 是由 `C 语言标准预先规定、具有特殊含义的单词`。

::: details 点我查看 具体细节

* ① 关键字 = C 语言自己保留使用的单词。
* ② 程序员 `不能` 将 `关键字` 当成 `变量名`、`函数名` 以及 `结构体` 等标识符去使用。
* ③ C 语言中的关键字是不需要强行记忆，等用到的时候，自然而然就记住了。
* ④ 在 `高级记事本软件` 或 `IDE`（集成开发环境中），`关键字` 非常好区分，因为其 `具有特殊的颜色`。
* ⑤ C 语言中的 `关键字` 定义了语言的语法和结构，并决定了程序的控制流、数据结构等方面的行为。

```c
#include <stdio.h>

// int 是关键字
int main() { // [!code highlight]

    printf("Hello World\n");

    // return 是关键字
    return 0; // [!code highlight]
}
```

## 1.2 标识符

### 1.2.1 概述

* 凡是程序员自己可以命名的部分就是标识符，如：变量名、函数名、结构体名等。

::: details 点我查看 具体细节

* ① 变量名，如下所示：

```c
#include <stdio.h>


int main() { 

    // age 是变量名，是标识符
    int age = 0 ;  // [!code highlight]

    return 0; 
}
```

* ② 函数名，如下所示：

```c
#include <stdio.h>

// add 是函数名，是标识符
int add(int a,int b){ // [!code highlight]
    return a + b;
}

int main() { 

    // result 是变量名，是标识符
    int result = add(1,2) ;  // [!code highlight]

    return 0; 
}
```

* ③ 结构体名，如下所示：

```c
#include <stdio.h>

// Student 是结构体名，是标识符
struct Student { // [!code highlight]
    int age;
};

int main() { 

    // stu 是变量名，是标识符
    struct Student stu = {10}; // [!code highlight]

    return 0; 
}
```

### 1.2.2 标识符的命名规则（必须遵守，强制）

* C 语言中的 `标识符` 的 `命名规则` ，如下所示：

::: details 点我查看 具体细节

* ① 标识符只能使用 26 个英文字母（大小写）、数字（0-9）和下划线（_）。
* ② 标识符不能使用 C 语言的关键字。
* ③ 标识符不能以数字开头。
* ④ 标识符不能包含空格。
* ⑤ 标识符严格区分大小写。
* ⑥ 规则是硬性规定，一旦违反，程序就会在编译过程中报错。

::: 

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-09-06/2026-09-06-19-20-49.png)



* 示例：合法标识符（✅）

```c
#include <stdio.h>

int main() { 
    
    // age 是变量名，是标识符，合法 ✅
    char name[10] = "abc" ; // [!code highlight]
    
    // _count 是变量名，是标识符，合法 ✅
    int _count = 0 ; //[!code highlight]
    
    // stu1 是变量名，是标识符，合法 ✅
    int stu1 = 0 ; //[!code highlight]
    
    // student_name 是变量名，是标识符，合法 ✅
    char student_name[10] = "Tom" ; //[!code highlight]

    return 0; 
}
```



* 示例：非法标识符（❌）

```c
#include <stdio.h>

int main() { 

    // 1age 是变量名，是标识符，非法 ❌ ，原因：标识符不能以数字开头
    int 1age = 0 ;  // [!code error]
    
    // int 是变量名，是标识符，非法 ❌，原因：标识符不能使用 C 语言的关键字。
    char int = '0' ;  // [!code error]
    
    // my name 是变量名，是标识符，非法 ❌，原因：标识符不能包含空格。
    char my name = "Tom" ;  // [!code error]

    return 0; 
}
```

### 1.2.3 标识符的命名规范（柔性规范，非强制）

* C 语言中的 `标识符` 的 `命名规范` ，如下所示：

::: details 点我查看 具体细节

* ① 常见的 C 语言命名规范，如下所示：

| 类型                   | 推荐命名                 | 示例                                        |
| ---------------------- | ------------------------ | ------------------------------------------- |
| 普通变量               | 小写字母 + 下划线        | `user_name`、`student_count`                |
| 局部变量               | 简短但有意义             | `index`、`count`、`buffer`                  |
| 函数                   | 动词或“动词 + 名词”     | `get_user()`、`read_file()`、`print_info()` |
| 结构体变量             | 小写 + 下划线            | `user_info`                                 |
| `struct` / `enum` 标签 | 小写 + 下划线较常见      | `struct user_info`                          |
| 宏                     | 全大写 + 下划线          | `MAX_SIZE`、`DEFAULT_PORT`                  |
| 枚举常量               | 全大写 + 下划线          | `STATUS_OK`、`STATUS_ERROR`                 |
| 全局变量               | 最好加模块前缀           | `config_path`、`net_timeout`                |
| 布尔含义变量           | `is_`、`has_`、`can_` 等 | `is_ready`、`has_error`                     |

* ②  编译器并不强制，但为了让代码更清晰、统一、易维护，开发中通常遵循的命名习惯。

::: 

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-09-06/2026-09-06-19-35-58.png)



* 示例：推荐的写法

```c
#include <stdio.h>

int main() {

    // name：含义清楚，推荐 👍
    char name[10] = "abc"; // [!code highlight]

    // student_count：见名知意，snake_case，推荐 👍
    int student_count = 0; // [!code highlight]

    // student_name：见名知意，snake_case，推荐 👍
    char student_name[10] = "Tom"; // [!code highlight]

    // is_ready：布尔含义清楚，推荐 👍
    int is_ready = 1; // [!code highlight]

    return 0;
}
```



* 示例：不推荐的写法

```c
#include <stdio.h>

int main() {

    // a：名字含义不清，不推荐 ⚠️
    char a[10] = "abc"; // [!code warning]

    // _count：虽然合法，但不推荐自己以下划线开头 ⚠️
    int _count = 0; // [!code warning]

    // std_cnt：缩写过多，可读性较差，不推荐 ⚠️
    int std_cnt = 0; // [!code warning]

    // studentName：如果项目统一使用 snake_case，这种风格混用不推荐 ⚠️
    char studentName[10] = "Tom"; // [!code warning]

    return 0;
}
```

# 第二章：常量（🎯）

## 2.1 概述

* `常量`（Constant）指的是在程序运行过程中，其值不会发生改变的量（数据），如下所示：

::: code-group

```c [main.c]
#include <stdio.h>

int main(void) {
    /*
     * 10 、3.14 、'A' 、"Hello" 都是常量，这些直接写在代码中的固定值，都是常量。
     */
    // 10 是常量
    printf("%d\n", 10); // [!code highlight]
    // 3.14 是常量
    printf("%.2f\n", 3.14); // [!code highlight]
    // 'A' 是常量
    printf("%c\n", 'A'); // [!code highlight]
    // "Hello" 是常量
    printf("%s\n", "Hello"); // [!code highlight]

    return 0;
}
```
