# 第一章：关键字和标识符（🔥）

## 1.1 关键字

### 1.1.1 概述

* 在 C 语言中，`关键字` 是由 `C 语言标准预先规定、具有特殊含义的单词`。

::: details 点我查看 具体细节

* ① 关键字 = C 语言自己保留使用的单词。
* ② 程序员 `不能` 将 `关键字` 当成 `变量名`、`函数名` 以及 `结构体` 等标识符去使用。
* ③ C 语言中的关键字是不需要强行记忆，等用到的时候，自然而然就记住了。
* ④ 在 `高级记事本软件` 或 `IDE`（集成开发环境中），`关键字` 非常好区分，因为其 `具有特殊的颜色`。
* ⑤ C 语言中的 `关键字` 定义了语言的语法和结构，并决定了程序的控制流、数据结构等方面的行为。

```c
#include <stdio.h>

// int 是关键字
int main() { // [!code highlight]

    printf("Hello World\n");

    // return 是关键字
    return 0; // [!code highlight]
}
```

## 1.2 标识符

### 1.2.1 概述

* 凡是程序员自己可以命名的部分就是标识符，如：变量名、函数名、结构体名等。

::: details 点我查看 具体细节

* ① 变量名，如下所示：

```c
#include <stdio.h>


int main() { 

    // age 是变量名，是标识符
    int age = 0 ;  // [!code highlight]

    return 0; 
}
```

* ② 函数名，如下所示：

```c
#include <stdio.h>

// add 是函数名，是标识符
int add(int a,int b){ // [!code highlight]
    return a + b;
}

int main() { 

    // result 是变量名，是标识符
    int result = add(1,2) ;  // [!code highlight]

    return 0; 
}
```

* ③ 结构体名，如下所示：

```c
#include <stdio.h>

// Student 是结构体名，是标识符
struct Student { // [!code highlight]
    int age;
};

int main() { 

    // stu 是变量名，是标识符
    struct Student stu = {10}; // [!code highlight]

    return 0; 
}
```

### 1.2.2 标识符的命名规则（必须遵守，强制）

* C 语言中的 `标识符` 的 `命名规则` ，如下所示：

::: details 点我查看 具体细节

* ① 标识符只能使用 26 个英文字母（大小写）、数字（0-9）和下划线（_）。
* ② 标识符不能使用 C 语言的关键字。
* ③ 标识符不能以数字开头。
* ④ 标识符不能包含空格。
* ⑤ 标识符严格区分大小写。
* ⑥ 规则是硬性规定，一旦违反，程序就会在编译过程中报错。

::: 

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-09-06/2026-09-06-19-20-49.png)



* 示例：合法标识符（✅）

```c
#include <stdio.h>

int main() { 
    
    // age 是变量名，是标识符，合法 ✅
    char name[10] = "abc" ; // [!code highlight]
    
    // _count 是变量名，是标识符，合法 ✅
    int _count = 0 ; //[!code highlight]
    
    // stu1 是变量名，是标识符，合法 ✅
    int stu1 = 0 ; //[!code highlight]
    
    // student_name 是变量名，是标识符，合法 ✅
    char student_name[10] = "Tom" ; //[!code highlight]

    return 0; 
}
```



* 示例：非法标识符（❌）

```c
#include <stdio.h>

int main() { 

    // 1age 是变量名，是标识符，非法 ❌ ，原因：标识符不能以数字开头
    int 1age = 0 ;  // [!code error]
    
    // int 是变量名，是标识符，非法 ❌，原因：标识符不能使用 C 语言的关键字。
    char int = '0' ;  // [!code error]
    
    // my name 是变量名，是标识符，非法 ❌，原因：标识符不能包含空格。
    char my name = "Tom" ;  // [!code error]

    return 0; 
}
```

### 1.2.3 标识符的命名规范（柔性规范，非强制）

* C 语言中的 `标识符` 的 `命名规范` ，如下所示：

::: details 点我查看 具体细节

* ① 常见的 C 语言命名规范，如下所示：

| 类型                   | 推荐命名                 | 示例                                        |
| ---------------------- | ------------------------ | ------------------------------------------- |
| 普通变量               | 小写字母 + 下划线        | `user_name`、`student_count`                |
| 局部变量               | 简短但有意义             | `index`、`count`、`buffer`                  |
| 函数                   | 动词或“动词 + 名词”     | `get_user()`、`read_file()`、`print_info()` |
| 结构体变量             | 小写 + 下划线            | `user_info`                                 |
| `struct` / `enum` 标签 | 小写 + 下划线较常见      | `struct user_info`                          |
| 宏                     | 全大写 + 下划线          | `MAX_SIZE`、`DEFAULT_PORT`                  |
| 枚举常量               | 全大写 + 下划线          | `STATUS_OK`、`STATUS_ERROR`                 |
| 全局变量               | 最好加模块前缀           | `config_path`、`net_timeout`                |
| 布尔含义变量           | `is_`、`has_`、`can_` 等 | `is_ready`、`has_error`                     |

* ②  编译器并不强制，但为了让代码更清晰、统一、易维护，开发中通常遵循的命名习惯。

::: 

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-09-06/2026-09-06-19-35-58.png)



* 示例：推荐的写法

```c
#include <stdio.h>

int main() {

    // name：含义清楚，推荐 👍
    char name[10] = "abc"; // [!code highlight]

    // student_count：见名知意，snake_case，推荐 👍
    int student_count = 0; // [!code highlight]

    // student_name：见名知意，snake_case，推荐 👍
    char student_name[10] = "Tom"; // [!code highlight]

    // is_ready：布尔含义清楚，推荐 👍
    int is_ready = 1; // [!code highlight]

    return 0;
}
```



* 示例：不推荐的写法

```c
#include <stdio.h>

int main() {

    // a：名字含义不清，不推荐 ⚠️
    char a[10] = "abc"; // [!code warning]

    // _count：虽然合法，但不推荐自己以下划线开头 ⚠️
    int _count = 0; // [!code warning]

    // std_cnt：缩写过多，可读性较差，不推荐 ⚠️
    int std_cnt = 0; // [!code warning]

    // studentName：如果项目统一使用 snake_case，这种风格混用不推荐 ⚠️
    char studentName[10] = "Tom"; // [!code warning]

    return 0;
}
```

# 第二章：常量（🎯）

## 2.1 概述

* `常量`（Constant）指的是在程序运行过程中，其值不会发生改变的量（数据），如下所示：

::: code-group

```c [main.c]
#include <stdio.h>

int main(void) {
    /*
     * 10 、3.14 、'A' 、"Hello" 都是常量，这些直接写在代码中的固定值，都是常量。
     */
    // 10 是常量
    printf("%d\n", 10); // [!code highlight]
    // 3.14 是常量
    printf("%.2f\n", 3.14); // [!code highlight]
    // 'A' 是常量
    printf("%c\n", 'A'); // [!code highlight]
    // "Hello" 是常量
    printf("%s\n", "Hello"); // [!code highlight]

    return 0;
}
```

#### 2.2.2.2 不同进制（🌱）

* C 语言中的整数可以使用不同的进制来表示。

> [!NOTE]
>
> * ① 默认的数字就是十进制。
> * ② 八进制需要以 0 开头，数字范围是 0 - 7 的范围，如：012。
> * ③ 十六进制需要以 0x 开头，数字范围是 0 - 9 以及 a - z（A-Z），如：0xA。
> * ④ 二进制需要以 0b 开头，数字范围是 0 - 1，如：0b1010。



* 示例：

::: code-group

```c [main.c]
#include <stdio.h>

int main(void) {
    /*
     * C 语言中的整数可以使用不同的进制来表示
     * ① 十进制：0-9 的数字，默认，如：10
     * ② 八进制：0-7 的数字，以 0 开头，如： 012 表示 8 进制的 10
     * ③ 十六进制：0-9 和 A-F 的数字，以 0x 开头，如： 0xA 表示 16 进制的 10
     * ④ 二进制：0-1 的数字，以 0b 开头，如： 0b1010 表示 2 进制的 10
     */
    printf("%d\n", 10);     // 10
    printf("%d\n", 012);    // 10
    printf("%d\n", 0xA);    // 10
    printf("%d\n", 0b1010); // 10
    return 0;
}
```

#### 2.2.2.3 整数常量后缀（🌱）

* 整数常量可以通过后缀来指定类型，如下所示：

| 常量后缀            | 实际数据类型       | 有符号占位符 (Signed) <br>0、正整数和负整数 | 无符号占位符 (Unsigned) <br> 0 和正整数 |
| ------------------- | ------------------ | -------------------------------------------- | --------------------------------------- |
| **无后缀**          | int                | %d                                           | -                                       |
| **U / u**           | unsigned int       | -                                            | %u                                      |
| **L / l**           | long               | %ld                                          | -                                       |
| **UL / ul / LU**    | unsigned long      | -                                            | %lu                                     |
| **LL / ll**         | long long          | %lld                                         | -                                       |
| **ULL / ull / LLU** | unsigned long long | -                                            | %llu                                    |



* 示例：

::: code-group

```c [main.c]
#include <stdio.h>

int main(void) {

    printf("unsigned long = %lu\n", 100UL);
    printf("long long = %lld\n", 100LL);
    printf("unsigned long long = %llu\n", 100ULL);

    return 0;
}
```

#### 2.2.3.3 浮点常量后缀（🌱）

* 浮点常量可以通过后缀来指定类型，如下所示：

| 常量后缀   | 实际数据类型  | 占位符（十进制） | 占位符（科学计数法） |
| ---------- | ------------- | ---------------- | -------------------- |
| **无后缀** | `double`      | `%f` 或 `%lf`    | `%e` 或 `%le`        |
| **f / F**  | `float`       | `%f`             | `%e`                 |
| **l / L**  | `long double` | `%Lf`            |                      |



* 示例：

::: code-group

```c [main.c]
#include <stdio.h>

int main(void) {
    // 浮点常量
    printf("float       = %f\n", 3.14f);
    printf("double      = %f\n", 3.14159265358979);
    printf("long double = %Lf\n", 3.14159265358979323846L);

    // 科学计数法
    printf("double (sci) = %e\n", 3.14159265358979);

    // 控制小数位数
    printf("double (.2f) = %.2f\n", 3.14159265358979);
    return 0;
```

### 2.3.5 布尔常量的运算

#### 2.3.5.1 概述

* 在 C 语言中，**布尔常量** 用于表示逻辑上的“真”与“假”。

> [!NOTE]
>
> * ① 从 **C23 标准** 开始，C 语言引入了 `<stdbool.h>` 头文件，提供了原生的布尔类型 `bool` 以及布尔常量 **`true`** 和 **`false`**。
> * ② 要理解布尔常量的运算，首先需要牢记它的 **核心本质**：在 C 语言底层，`true` 就是整数 `1`，`false` 就是整数 `0`。

#### 2.3.5.2 逻辑运算（最常用）

* `逻辑运算 ` 用于组合多个条件，其结果只能是 `true` (1) 或 `false` (0)。

| 运算符   | 名称         | 规则                       | 示例            | 结果        |
| -------- | ------------ | -------------------------- | --------------- | ----------- |
| **`&&`** | 逻辑与 (AND) | **全真才为真**，一假即为假 | `true && false` | `false` (0) |
| **`||`** | 逻辑或 (OR)  | **一真即为真**，全假才为假 | `true || false` | `true` (1)  |
| **`!`**  | 逻辑非 (NOT) | **真变假，假变真**         | `!true`         | `false` (0) |



* 示例：

::: code-group

```c [main.c]
#include <stdio.h>

int main(void) {
    /*
     * C 语言中打印布尔值通常使用 %d，因为底层它会被当作整数 0 或 1 输出。
     */
    printf("a && b = %d\n", true && false); // 输出 0 (false)
    printf("a || b = %d\n", true || false); // 输出 1 (true)
    printf("!a = %d\n", !true);             // 输出 0 (false)

    return 0;
}
```

#### 2.5.3.3 关键特性：短路求值

* 逻辑运算中极其重要的特性，能帮我们避免很多 Bug 并优化代码，如下所示：

| 短路求值    | 描述                                                         |
| ----------- | ------------------------------------------------------------ |
| `&&` 的短路 | 如果左边的表达式为 `false`，则 `不再计算` 右边的表达式，直接返回 `false`。 |
| `||` 的短路 | 如果左边的表达式为 `true`，则 `不再计算` 右边的表达式，直接返回 `true`。 |



* 示例：

::: code-group

```c [main.c]
#include <stdio.h>

static int check_right() {
    printf("右边被计算了！\n");
    return true;
}

int main() {
    // 1. && 短路：左边是 false，右边不会被执行
    if (false && check_right()) {
        // ...
    }
    // 输出：什么都没有（右边没被计算）

    // 2. || 短路：左边是 true，右边不会被执行
    if (true || check_right()) {
        // ...
    }
    // 输出：什么都没有（右边没被计算）

    return 0;
}
```

#### 2.5.3.4 ~~算术运算（布尔值当数字用）~~

* 当布尔值参与算术运算时，会发生 `整型提升`，结果的类型是 `int`，而不是 `bool`。

> [!NOTE]
>
> * ① 因为 `true` 是 1，`false` 是 0，所以布尔常量 `可以直接参与加减乘除等算术运算`。
> * ② 不建议这种用法，因为很多编程语言压根不支持这种隐式转换。



* 示例：

::: code-group

```c [main.c]
#include <stdio.h>
#include <stdbool.h>

int main() {
    // 1. 布尔值相加（常用于统计 true 的个数）
    int count = true + true + false + true; 
    printf("count = %d\n", count);  // 输出 3 (1 + 1 + 0 + 1)

    // 2. 布尔值相乘
    printf("true * false = %d\n", true * false); // 输出 0

    // 3. 布尔值作为数组索引或偏移量
    int arr[2] = {100, 200};
    bool is_second = true;
    printf("arr[true] = %d\n", arr[is_second]);  // 输出 200 (相当于 arr[1])

    return 0;
}
```

#### 2.5.3.5 关系运算（产生布尔结果）

* 关系运算符（`>`, `<`, `==`, `!=` 等）用于比较两个值，它们的运算结果本身就是布尔常量。



* 示例：

::: code-group

```c [main.c]
#include <stdio.h>
#include <stdbool.h>

int main() {
    // 关系运算的结果可以直接赋值给 bool 变量
    bool is_greater = (10 > 5);
    bool is_equal = (3 == 4);

    printf("10 > 5 is %d\n", is_greater); // 输出 1 (true)
    printf("3 == 4 is %d\n", is_equal);   // 输出 0 (false)

    return 0;
}
```
