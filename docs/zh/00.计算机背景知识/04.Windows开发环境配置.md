## 1.2 替换 winget 源和 scoop 源

### 1.2.1 概述

* 默认的 winget 源或 scoop 源很慢，需要替换为国内源。

### 1.2.2 winget 源替换

* 默认的 winget 源很慢，可以替换为国内源：

```powershell
# 先删除较慢的官方 winget 源
winget source remove winget
# 将中科大的镜像源添加进去，并取名为 winget
winget source add winget https://mirrors.ustc.edu.cn/winget-source --trust-level trusted
# 刷新并检查
winget source update
winget source list
```

> [!NOTE]
>
> * ① 修改 WinGet 软件源需要管理员权限，请以管理员身份运行终端。对于 [启用 sudo](https://learn.microsoft.com/windows/advanced-settings/sudo/#how-to-enable-sudo-for-windows) 的 Windows 11 用户，也可以使用 `sudo` 进行提权。
> * ② 重置为官方地址，可以使用如下的命令：
>
> ```powershell
> winget source reset winget
> ```



* 示例：

::: code-group

```powershell
winget source remove winget
winget source add winget https://mirrors.ustc.edu.cn/winget-source --trust-level trusted
winget source update
winget source list
```

### 1.2.3 Scoop 源替换

* 默认的 scoop 源很慢，可以替换为国内源：

```powershell
# 先删除较慢的官方 scoop 源
scoop bucket rm main
scoop bucket rm extras
scoop bucket rm versions
scoop bucket rm nerd-fonts
scoop bucket rm nonportable
scoop bucket rm nirsoft
scoop bucket rm java
# 替换为国内镜像源
scoop bucket add main https://mirror.nju.edu.cn/git/scoop-main.git
scoop bucket add extras https://mirror.nju.edu.cn/git/scoop-extras.git
scoop bucket add versions https://mirror.nju.edu.cn/git/scoop-versions.git
scoop bucket add nerd-fonts https://mirror.nju.edu.cn/git/scoop-nerd-fonts.git
scoop bucket add nonportable https://mirror.nju.edu.cn/git/scoop-nonportable.git
scoop bucket add nirsoft https://mirror.nju.edu.cn/git/scoop-nirsoft.git
scoop bucket add java https://mirror.nju.edu.cn/git/scoop-java.git
# 刷新测试
scoop update
```

> [!NOTE]
>
> * ① 可以使用如下的命令，切换 scoop 核心源：
>
> ```powershell
> scoop config scoop_repo https://mirror.nju.edu.cn/git/scoop.git
> ```
>
> * ② 从国内源恢复至官方源：
>
> ```powershell
> scoop bucket rm main
> scoop bucket rm extras
> scoop bucket rm versions
> scoop bucket rm nerd-fonts
> scoop bucket rm nonportable
> scoop bucket rm nirsoft
> scoop bucket rm java
> 
> scoop bucket add main
> scoop bucket add extras
> scoop bucket add versions
> scoop bucket add nerd-fonts
> scoop bucket add nonportable
> scoop bucket add nirsoft
> scoop bucket add java
> ```



* 示例：

::: code-group

```powershell

# 激活
# ① 创建目录
# PowerShell 5.1 用户
if (!(Test-Path "$HOME\Documents\WindowsPowerShell")) {
    New-Item -Path "$HOME\Documents\WindowsPowerShell" -ItemType Directory
}
# PowerShell 7+ 用户
if (!(Test-Path "$HOME\Documents\PowerShell")) {
   New-Item -Path "$HOME\Documents\PowerShell" -ItemType Directory
}

# ② 写入 mise 初始化命令
# PowerShell 5.1 用户
"`n`$env:MISE_PWSH_CHPWD_WARNING = 0" | Add-Content $PROFILE
'(&mise activate pwsh) | Out-String | Invoke-Expression' | Add-Content -Path "$HOME\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1"
# PowerShell 7+ 用户
"`n`$env:MISE_PWSH_CHPWD_WARNING = 0" | Add-Content $PROFILE
'(&mise activate pwsh) | Out-String | Invoke-Expression' | Add-Content -Path "$HOME\Documents\PowerShell\Microsoft.PowerShell_profile.ps1"

# ③ 验证配置文件内容
notepad $PROFILE  # (&mise activate pwsh) | Out-String | Invoke-Expression

# ④ 重新加载配置
. $PROFILE
```

# 第二章：Tabby

## 2.1 概述

* [Tabby](https://github.com/eugeny/tabby) 是一款现代化、高度可配置的 `跨平台终端工具`，其前身叫做 Terminus 。

![](https://github-pic.oss-cn-hangzhou.aliyuncs.com/linux/2026-07-04/2026-07-04-08-04-55.png)

* 其主要作用，如下所示：

| 主要作用            | 描述                                                         |
| ------------------- | ------------------------------------------------------------ |
| `全能的连接管理`    | 它不仅仅是一个本地命令行终端，还内置了强大的 SSH 客户端、串口（Serial）连接和 Telnet 支持。如果需要远程连接服务器或管理网络设备，它是一个非常方便的集成工具。 |
| `高度可定制化`      | Tabby 提供了极其丰富的主题、配色方案和快捷键自定义功能，您可以根据自己的喜好打造个性化的终端界面 。 |
| `跨平台与现代化 UI` | 完美支持 Windows 11、macOS 和 Linux，拥有现代化的 UI 设计，支持分屏（Split Panes）、标签页管理以及插件扩展系统。 |
| `便捷的功能`        | 内置了 SFTP 文件传输、ZMODEM 支持、以及保存 SSH 密码/密钥的连接管理器，极大提升了运维和开发效率。 |
